# Security Policy

## Supported version

Security fixes are provided for the latest release.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Include the affected version, reproduction steps, expected behavior, and the observed impact. Do not publish credentials, private World data, licensed adventure content, or server addresses in an issue.

## Operational guidance

- Back up the World before the first persistent run.
- Restrict module operations to trusted GM accounts.
- Review the placement preview before creating Tokens.
- Stop Foundry before replacing module files manually.
- Treat third-party modules and imported Actors as separate trust boundaries.
